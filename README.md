**The Gilded Hour** — a top-down 3D stealth game set in the Meridian Gallery at night. You are Wren, a thief in a borrowed cloak. Slip past four named guards with learnable patrols (Sgt. Marlowe, Pip, Odo, Bram), steal the Meridian Star and the gallery's named loot, and vanish through the skylight — unseen, if you can manage it.

- Vision cones that change colour with suspicion (yellow calm → orange suspicious → red hunting), with line of sight blocked by walls and cover
- A detection meter that fills in lamplight and drains in shadow, so you always have a chance to recover
- Cover you can read at a glance: pillars, crates, plinths, velvet ropes, plants, and dark shadow pools
- Tools: sneak, tossed coins that distract the nearest guard, loot to grab, a minimap, and a ghost bonus for never being spotted
- Synthesised sound only (WebAudio footsteps panned by direction and distance, alarm sting, pickup chimes) — no audio files, no network

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows move, SHIFT sneaks, CLICK tosses a coin, E grabs loot, P pauses, M mutes.
